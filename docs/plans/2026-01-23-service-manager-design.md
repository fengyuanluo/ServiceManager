# Linux Web 服务管理器 设计说明

## 目标
构建一个可在 Ubuntu 20.04+、Debian 11+、Alpine 3.18+ 运行的 Linux Web 服务管理器，支持 systemd、SysV、OpenRC、supervisor、PM2，提供统一登录入口、分区式管理器页面、批量操作、日志检索与导出，并支持纯静态前端 + 单文件后端部署。

## 范围与约束
- 后端：Go（现有脚手架），JWT 单用户登录复用
- 前端：Vue3 + Vite + PNPM + Shadcn + Tailwind
- 静态构建输出到 `static`，后端 `embed` 单文件部署
- 仅供 Web UI 使用，不提供外部稳定 API
- 后端以 root 运行
- 单元测试：前后端分别达到 75%+
- 主题：纯白/深色/浅粉/淡青/书卷 五套预设，后续可扩展

## 信息架构（方案 B）
- 以“管理器分区”组织导航：systemd / SysV / OpenRC / supervisor / PM2
- 全局区域：环境与受限模式提示、主题切换、语言切换
- PM2 支持选择用户（默认 root）

## 响应式与视觉方向
- 桌面端：左侧分区导航 + 主内容双栏（列表/详情）
- 移动端：左侧抽屉菜单 + 单列内容 + 底部操作区
- 视觉风格：精致、克制、优雅；文本极简但排版细腻
- 文本减少但信息密度高，必要说明放入悬浮提示/抽屉

## 后端架构
### 模块划分
- 领域层：统一 DTO（列表/详情/日志/批量结果）
- 适配器层：systemd、SysV、OpenRC、supervisor、PM2 独立实现
- 基础设施层：命令执行、环境检测、包管理安装、文件读写/备份
- 接口层：按管理器分组路由

### 能力矩阵
- 环境检测：OS 发行版、init 系统、容器/CHROOT 限制
- 输出可用性与受限原因，前端据此禁用功能并展示提示

### 批量操作
- 支持：启动/停止/重启/删除/开机自启
- 返回逐项结果（支持部分失败）

### 日志
- 默认返回最近 N 行
- 支持过滤/搜索/导出下载
- 优先使用各管理器原生命令；不支持时给出明确提示

### 编辑/查看服务
- 表单为默认（通用字段 + 管理器扩展区）
- 支持切换到原始文本编辑
- 写入前进行备份与校验

## 前端架构
- 统一列表页：快速扫描展示轻量字段
- 详情页：深度加载（配置/状态/日志）
- 操作确认：敏感操作弹出确认
- 国际化：中/英内置字典

## 构建与部署
- 前端构建输出到 `static`
- Go 后端 `embed` 静态资源
- GitHub Actions 并行多平台构建
- 单文件 Bash 安装脚本（检测→确认→安装）

## 测试策略
- 后端：单元测试覆盖命令解析、环境检测、日志解析、批量操作
- 前端：组件单测 + 关键交互覆盖
- 覆盖率目标：前后端各 75%+
